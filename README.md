# Auric Turrets — Vista previa del jefe final (M17)

Repositorio privado de pruebas, separado del juego principal. El modelo 3D es un **prototipo original no aprobado** para revisar proporciones, silueta, Núcleo central, identidad del antagonista y transformaciones; no reemplaza arte aprobado ni modifica la versión del juego.

El proyecto utiliza Godot 4.x y geometría 3D nativa construida mediante un script, sin recursos externos. Abrir `project.godot` y ejecutar la escena `scenes/BossPreview.tscn` para visualizar el traje. El selector `Phase` del nodo raíz presenta cinco fases. Al exportar GLB desde Godot se obtiene geometría real.

**Estado:** planificación visual, no integrado ni validado en el juego. Cambios solo después de la aprobación del dueño.
